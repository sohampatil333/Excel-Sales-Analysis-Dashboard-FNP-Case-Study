# 📊 Sales Analysis Dashboard (Excel) | FNP Case Study

![Dashboard Preview](Dashboard_Preview.png)

## 🎯 Objective  
To visualize and analyze key business metrics — from revenue trends and top-selling categories to delivery timelines and customer behavior.

---

## 💡 What This Dashboard Reveals  
- ₹35+ Lakhs in revenue from 1000+ orders  
- Top occasions: **Anniversary** & **Raksha Bandhan**  
- Best-performing categories: **Colors**, **Soft Toys**, **Sweets**  
- Deep dives by **city**, **month**, **hour**, and **product line**

---

## 🧠 Tools & Techniques Used  
- **Power Query Editor** – for data cleaning & modeling  
- **Power Pivot** – to build complex data relationships  
- **Slicers & Timelines** – for interactive filtering  
- **Dynamic Charts** – for intuitive, user-friendly visuals  

---

## 🧰 Skills Demonstrated  
`Microsoft Excel` • `Power Query` • `Power Pivot` • `Data Visualization` • `Business Analytics`

---

## 📈 Dashboard Features  
| Feature | Description |
|--------|-------------|
| **Revenue by Occasion** | Compare sales across events (Diwali, Holi, Valentine’s Day, etc.) |
| **Revenue by Category** | Identify which product categories perform best |
| **Revenue by Hour** | See hourly order trends across the day |
| **Revenue by Month** | Observe monthly sales trends |
| **Top 5 Products by Revenue** | List highest revenue-generating products |
| **Top 10 Cities by Orders** | Analyze which cities contribute the most orders |

---

## 📂 How to Use  
1. Download the Excel file from this repository.  
2. Open it in **Microsoft Excel 2019 or later**.  
3. Use the **slicers and timelines** to filter data interactively.  
4. Explore the KPI cards and charts for insights.
